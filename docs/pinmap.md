# K10 V2.1 (GD32F303CBT6) ピンマップ — 純正ファーム解析結果

出典: SWDダンプ `dump/k10_flash_1.bin` (SHA256 BE649BF4…9E93) の静的解析 + 動作中のRAM/レジスタ読み出し (2026-09-21)

## フラッシュ構成
| 範囲 | 内容 |
|---|---|
| 0x08000000–0x08003FFF | SDブートローダ (`1:/p10_printer.bin` → 書込後 `P10_PRINTER.CUR` にリネーム) |
| 0x08004000–0x0801CE96 | 純正アプリ (~102KB) |
| 0x0801F800–0x0801F8C7 | 設定領域 (`k10_cfg.txt` 由来) |
- 読み出し保護なし (OB 0x5AA5)。フラッシュ128KB。
- 純正はGD32標準ライブラリ直叩き。GPIOは RAM上の表 (port 0x20000754 / mask 0x2000079c, 18項目) 経由。

## ⚠ 実機確認 (2026-09-21): 純正内部の軸順とコネクタのシルクは Y/E が逆
| コネクタ (シルク) | STEP | DIR | 純正内部の軸 |
|---|---|---|---|
| X (赤) | PC15 | PC14 | X |
| Y (黒) | PA11 | PA12 | E |
| Z (青) | PA9 | PA10 | Z |
| E (白) | PC13 | PA8 | Y |
下の表は「純正内部の軸名」で書いてある。Marlin 設定 (pins_custom.h) はコネクタ基準で修正済み。

## ステッパ (HR4988SQ ×4) — 純正ファーム内部の軸名
| 軸 | STEP | DIR | EN | 純正 INVERT_DIR | 純正 steps/mm |
|---|---|---|---|---|---|
| X | PC15 | PC14 | PB9 | 1 | 606 |
| Y | PC13 | PA8  | PB9 | 1 | 606 |
| Z | PA9  | PA10 | PB9 | 1 | 600 |
| E | PA11 | PA12 | PB9 | 1 | 1040 |
- EN は4ドライバ共通、Lowで有効。起動時は High(無効)。
- 根拠: stepper init (0x0800B280) が表の奇数idxを STEP として Low、DIR設定 (0x0800AD64) が軸0..3 に偶数idx を使用。HWテスト (0x0801B5C2/0x0801B634) も同じ組分け。
- PA9/PA10(UART1)、PA11/PA12(USB) はステッパに使用済み → USB-Cはデータ非対応、UART1も使えない。

## モーター電流 VREF (PWM, 要注意)
| ピン | タイマ | 純正デューティ | VREF | 電流 (Rs=0.1Ω) |
|---|---|---|---|---|
| PB5 | TIMER2_CH1 (部分リマップ) | 145/750 | 0.64V | 約0.80A |
| PB6 | TIMER3_CH0 | 145/750 | 0.64V | 約0.80A |
| PB7 | TIMER3_CH1 | 127/750 | 0.56V | 約0.70A |
| PB8 | TIMER3_CH2 | 127/750 | 0.56V | 約0.70A |
- PSC=4, CAR=749 → 約19.2kHz。RCで平滑して HR4988 REF へ入ると推定。
- どのピンがどの軸かは未確定 (PB5,6=X,Y / PB7,8=Z,E と推定)。ドライバREF(17番)からの導通で確認する。
- **ファームでこのPWMを出さないとモーターは動かない。High固定だと VREF=3.3V → 約4A設定で危険。**

## その他
| ピン | 設定 | 推定用途 |
|---|---|---|
| PA2 | アナログ入力 | サーミスタ (TH) — 表idx10 |
| PB3 | 出力 (起動時Low) | **ヒーター** — 温度ISRの7bitソフトPWM (`cmp #0x7f`, 0x080126D6)、全ヒーター停止で0書込 (0x08012660)。表idx11 |
| PB4 | TIMER2_CH0 PWM (0%) | **ファン (動的解析で確定)**: M106 S128 で CV0 0→5019 (印刷中の周期10000)、S255 で10000、M107 で0 |
| PA1 | 出力 | ステータスLED — 状態に応じて速/遅点滅・点灯 (0x08012E30) |
| PA15 | 出力 (起動時High、以後不変) | 不明。ドライバ SLEEP/RESET 解除の可能性大 → 要導通確認。Marlinでも起動時Highにする |
| PA3 | 入力プルアップ | SDカード検出 (Lowで挿入、起動時マウント判定 0x0801B592 / 0x080086FA) |
| PB10 | 入力プルアップ | **表面の大きな ▷ (印刷開始) ボタン** (動的解析で確定) |
| PB0 / PB1 / PB12 / PB13 / PB14 / PB15 | 入力プルアップ | **裏面 S3 / S4 / S6 / S7 / S8 / S9** (動的解析で確定、押下で Low) |
| PA4 | 出力 (High) | SD CS |
| PA5/PA6/PA7 | SPI0 | SD SCK/MISO/MOSI |
| PA13/PA14 | SWD | ヘッダ 1=SWDIO, 3=SWCLK, 2=3V3, 4=GND, 5=NRST, 6=VSSA |
| PA0, PB2, PB11 | 未使用 (フローティング入力) | 空きピン候補 |
- AFIO: JTAG無効/SWD有効 (PA15/PB3/PB4 解放)、TIMER2 部分リマップ。
- エンドストップ入力に該当するものは見当たらない。

## 動的解析 (2026-09-21, k10\dynamic)
- SD の `K10TEST.gcode` を純正ファームで実行し、OpenOCD の TCL ポート経由で CPU を止めずにレジスタを監視
- ファン/ボタンは上表のとおり確定
- `M104 S45` で純正の `kill()` (0x08007610) に入り停止。サーミスタ ADC = 0xFCA (開放状態) → MINTEMP。ヒーター PB3 の動的確認と M17/M18 は未実施
- 純正ファームは `.GCO` 拡張子のファイルを実行、`G28` を使う (エンドストップなしの突き当て原点と推定)

## 純正の運動パラメータ (RAMから)
- max feedrate 候補: X/Y 3000, Z 240, E 60 (mm/min)
